# Git Commit Guide for Materialdex Revit Plugin

This document outlines which files should be committed to GitHub and which should be ignored.

## ✅ Files That SHOULD Be Committed

### Source Code
- `App.cs` - Main plugin entry point
- `MaterialExtractor.cs` - Material extraction logic
- `MaterialdexDockablePane.xaml` - WPF panel UI
- `MaterialdexDockablePane.xaml.cs` - Panel code-behind
- `Materialdex.csproj` - Project file
- `Materialdex.sln` - Solution file
- `Materialdex.addin` - Revit manifest (source version)

### Resources
- `Resources/materialdex-16.png` - Small icon
- `Resources/materialdex-32.png` - Large icon

### Documentation
- `README.md` - Main project documentation
- `APP_STORE_SUBMISSION.md` - App Store submission guide
- `BUNDLE_README.md` - Bundle package guide
- `INSTALLATION_INSTRUCTIONS.md` - Installation instructions
- `PACKAGING_SUMMARY.md` - Packaging summary
- `CONFIGURE_URL.md` - URL configuration guide

### Build Scripts
- `build.bat` - Build script
- `install.bat` - Installation script (legacy)
- `package-for-store.bat` - Package creation script
- `create-zip.bat` - ZIP creation script
- `install-bundle.bat` - Bundle installer script
- `verify-bundle.bat` - Bundle verification script
- `test-zip.bat` - ZIP testing script

## ❌ Files That Should NOT Be Committed (Already in .gitignore)

### Build Artifacts
- `bin/` - Compiled binaries and DLLs
- `obj/` - Build intermediate files
- `*.dll` - Compiled assemblies
- `*.pdb` - Debug symbols
- `*.cache` - Build cache files
- `*.g.resources` - Generated resources
- `*.baml` - Compiled XAML
- `*.g.cs` - Generated C# files
- `*.AssemblyInfo.cs` - Assembly info files

### Packaging Artifacts
- `Materialdex.bundle/` - **Packaged bundle (can be regenerated)**
- `Materialdex-v*.zip` - **Release ZIP files (can be regenerated)**
- `test-extract/` - **Test extraction folder (temporary)**

### NuGet Artifacts
- `*.nuget.dgspec.json`
- `*.nuget.g.props`
- `*.nuget.g.targets`
- `project.assets.json`
- `project.nuget.cache`

## 📝 Summary

**Commit these new files:**
- ✅ All `.md` documentation files
- ✅ All `.bat` script files
- ✅ Updated `README.md`

**Do NOT commit:**
- ❌ `Materialdex.bundle/` (regenerated by `package-for-store.bat`)
- ❌ `Materialdex-v*.zip` (regenerated by `create-zip.bat`)
- ❌ `test-extract/` (temporary test folder)
- ❌ `bin/` and `obj/` folders (build outputs)

## 🔄 Regenerating Package Files

If someone clones the repo, they can regenerate the bundle and ZIP files:

```cmd
cd RevitPlugin
package-for-store.bat
create-zip.bat
```

This will create:
- `Materialdex.bundle/` - Ready for installation
- `Materialdex-v0.1.0.zip` - Ready for App Store submission

## Notes

- The `.gitignore` file has been updated to exclude all build and packaging artifacts
- Source code, documentation, and scripts are version controlled
- Release packages are generated from source code, so they don't need to be in git
- This keeps the repository clean and focused on source code
